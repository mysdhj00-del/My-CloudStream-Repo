# My CloudStream Repo

All my CloudStream extensions in one repository.

## Add to CloudStream

Settings → Extensions → Add Repository → paste this URL:

```
https://raw.githubusercontent.com/mysdhj00-del/My-CloudStream-Repo/builds/repo.json
```

## Extensions

| Name | Description |
| --- | --- |
| EgyDead | Arabic dubbed/subtitled movies, series and anime (egydead) |
| AnimeZid | Arabic dubbed/subtitled anime, cartoons and movies (animezid.org) |

Pushing to `main` rebuilds all plugins automatically (GitHub Actions) and
publishes them to the `builds` branch.
